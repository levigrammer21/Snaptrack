SnapTrack v1.3.0 Test Checklist

Historical game edit
[ ] Games > Open a completed game > Timeline.
[ ] Tap a play. Edit Play modal opens.
[ ] Change one player on field; player count must equal the team requirement to save.
[ ] Save Changes. Timeline still has the same number of plays and the same play number.
[ ] Re-open the play and confirm the corrected players are saved.
[ ] Check Boxscore and Season stats; snap/stat totals reflect the corrected play.

Result edit
[ ] Tap an offensive play and change run/pass/special details, yards, TD/FUM/DS as appropriate.
[ ] Tap a defensive play and change tackler, assist, result, and opponent yards.
[ ] Save and confirm the timeline description and boxscore update.
[ ] Use Make Snap Only on a play and confirm individual result stats are removed while participation remains.

Live game edit
[ ] Record several test plays. Open Timeline while game is live.
[ ] Edit an earlier play, save, then continue recording new snaps normally.
[ ] Confirm Undo still removes only the latest play.

Persistence
[ ] Refresh/reopen the app after an edit and confirm the edited play remains.
[ ] Completed game stays completed after an edit.

v1.3.1 checks

2. New scrimmage: check Scrimmage before Start Live Game, score/end it, confirm game and boxscore retain stats while Season totals/leaders do not change.
3. Historical scrimmage: Games > Mark Scrimmage on a completed game. Confirm Season totals immediately drop that game's stats. Tap Count in Season to restore them.
4. Scrimmage editing: edit a play in a scrimmage and confirm its game boxscore changes but Season remains unaffected.
